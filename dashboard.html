The 5 Specialized Engineering Layers

LAYER 1 src/api.py

Reception Desk (Interfaces & Validation)

Ingests, validates, and serves requests via FastAPI REST microservices and an interactive Rich CLI. Strict Pydantic v2 data contracts intercept empty or malformed inputs before reaching AI models.

Validation: Pydantic v2 OpenAPI 3.0
LAYER 2 src/vector_store.py

Memory Vault (ChromaDB RAG)

Contains 23,859 paired historical British Airways customer/agent resolutions. Uses asymmetric indexing to retrieve the top-3 historically verified resolutions in under 15ms, completely eliminating hallucinations.

Search: Asymmetric Cosine Latency: ~12 ms
LAYER 3 src/schemas.py

7-Intent Operational Taxonomy

Mirrors real airline operations with 7 mutually exclusive operational categories (Flight Disruption, Baggage, Booking, Check-in, Refunds, Loyalty, FAQs). Avoids the boundary noise of 77 narrow classes.

Taxonomy: 7 Buckets 1:1 Department Mapping

Hybrid Triage Safety Guardrails

Deterministic regex and keyword safety checks for passenger welfare and privacy: public PNR codes, stranded travelers, lost luggage (WorldTracer PIR), and EU261 statutory claims. Delivers ≥ 96% escalation recall.

Safety: Deterministic Code Escalation Recall: 96.2%
